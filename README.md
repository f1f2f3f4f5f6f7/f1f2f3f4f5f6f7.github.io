# Kevin Daniel Castro Mendoza — Portfolio

Portfolio for a **Systems and Informatics Engineer** and **Full Stack / Backend
Developer**, built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

Professional content is maintained in the typed data files under `src/data`.

## Local dev

```bash
npm install
npm run dev
```

## Edit your info

| File | Content |
|------|---------|
| `src/data/profile.ts` | Identity, contact, summary, education, certifications |
| `src/data/experience.ts` | Work history |
| `src/data/projects.ts` | Projects & skill groups |

Keep these files aligned with the current CV and publish only validated metrics.

## Deploy

Push to `main` — GitHub Actions publishes to Pages (source: **GitHub Actions**).
