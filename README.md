# K. Daniel Castro Mendoza — Portfolio

Personal site built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

Content is synced with `CurriculumENGInch.tex`.

## Local dev

```bash
npm install
npm run dev
```

## Edit your info

| File | Content |
|------|---------|
| `src/data/profile.ts` | Contact, summary, education, certifications |
| `src/data/experience.ts` | Work history |
| `src/data/projects.ts` | Projects & skill groups |

## Deploy

Push to `main` — GitHub Actions publishes to Pages (source: **GitHub Actions**).
